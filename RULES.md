# Vultr: Agent Rush Hackathon — rules digest (fetched 2026-11-03 PT)
Source: https://lablab.ai/ai-hackathons/vultr-hackathon ; https://lablab.ai/delivering-your-hackathon-solution

- **Dates:** online build Nov 3–8, 2026; on-site phase Nov 8 at Pierpont Place, Salt Lake City (optional; travel not covered).
- **Deadline:** exact submission time NOT published ("Event Schedule: To be announced"). Plan for **Sat Nov 7 evening PT**; confirm on the lablab dashboard/Discord at kickoff.
- **Prizes:** 1st $5,000 + $3K Vultr credits; 2nd $3,000 + $1K; 3rd $1,000 + $1K; on-site raffle (PS5/AirPods/mouse). Payout may take up to 90 days.
- **Teams:** 1–6 people (solo OK). Register on lablab.ai (Enroll) AND the lablab Discord. "Everyone is welcome" — no rule found about AI-generated code; entrants are people (lablab accounts). Submissions must be **original and MIT-compliant**. Read the LabLab Hackathon Rule Book before submit (not fetched in full).
- **Tracks:** pick one.
  - **C1 Blast Radius Zero (our pick):** web agent that writes+runs code or drives a browser, every action in an isolated sandbox on Vultr. REQUIRED: Vultr VM backend, web app on Vultr, **Vultr Serverless Inference** (`https://api.vultrinference.com/v1`, OpenAI-compatible) for agent LLM calls, isolated sandbox (Docker recommended; gVisor/E2B/OpenSandbox/Microsandbox OK). Containment: process isolation, no secrets in sandbox, time/memory caps, destroy env after each task. **Show one containment moment in video.** Example "Research with Receipts" ≈ our idea.
  - C2 Future of Work: enterprise workflow app on Vultr VM; inference optional.
- **No Vultr GPUs** for this event.
- **Credits:** $200/participant. New Vultr account with an email never used at Vultr → verify email → Billing > promotion page > Gift Code (code given at kickoff).
- **Submission (on lablab.ai, required):** title (5–50 chars), short desc (50–255), long desc (600–2000), tech/category tags, participation mode (online/onsite), cover image 16:9 (optional), video MP4/MOV ≤300MB (<5 min rec.), slide PDF, **public GitHub repo**, demo platform + **public demo URL**. README must explain Vultr services, deployment architecture, use case. Vultr Community showcase optional.
- **Judging:** Application of Technology; Presentation; Business Value; Originality.
